  <files>backend/src/import/importer.ts, backend/src/storage/snapshots.ts</files>
  <action>
Implement importer logic that:
1) Resolves the repo default branch HEAD commit SHA.
2) Downloads the repo as a zipball for that SHA.
3) Stores the zip file under `backend/storage/snapshots/{bundleId}/{commitSha}.zip`.
4) Writes/updates `import_runs` and `snapshots` records, marking success/failure with clear error codes.

Constraints:
- Manual refresh only (no webhooks, no scheduled polling).
- Add basic guardrails: max zip size (e.g. 25MB) and timeouts; fail with a clear error code.
- Do not attempt "best-effort scanning" here; that belongs to Phase 2.
  </action>

`npm --prefix backend run lint && npm --prefix backend run build`
