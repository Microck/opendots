  <action>
Create a file index builder that extracts the file tree from a snapshot zip:
- `backend/src/import/fileIndex.ts`: Given a snapshot zip path, extract a list of `{ path, size, kind, isBinary }` entries. `kind` is derived from path conventions (e.g., `.opencode/themes/` → "theme", `SKILL.md` → "skill", `opencode.json` → "config"). Mark binary files (images, compiled) as non-previewable.
- Integrate into the importer: after a successful snapshot, persist the file index as JSON alongside the snapshot record (add a `fileIndex` text column to the snapshots table, or store as a JSON file next to the zip).

Create public (unauthenticated) bundle read endpoints:
- `GET /api/bundles/:id` → Returns bundle metadata (name, summary, tags, license, repoUrl), last import info (commitSha, importedAt, status), and the file index array. Reads from DB + snapshot, never hits GitHub.
- `GET /api/bundles/:id/file?path=<filepath>` → Returns file content as plain text from the snapshot zip. Enforce max preview size (e.g., 100KB). Return 404 for missing paths, 413 for oversized files.

Register these routes on the Fastify server.
