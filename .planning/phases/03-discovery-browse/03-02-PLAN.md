Create `frontend/src/api/bundles.ts`:

- `BrowseQuery` type: `{ q?: string, tags?: string[], artifactTypes?: string[], opencode?: string, sort?: 'newest' }`.
- Builds URL query string from params using `URLSearchParams`.
- Calls `GET /api/bundles?...` with the signal for cancellation.
- Returns typed `BundleCard[]`.

Create `frontend/src/hooks/useDebouncedValue.ts`:
- Generic debounce hook: `useDebouncedValue<T>(value: T, delay: number): T`.
- Returns the debounced value after `delay` ms of no changes.
- Use for the search text input to avoid firing a request on every keystroke.
- Default delay: 300ms.

  <action>
Replace the existing mock filter/search behavior with real URL-driven controls:

**Search (DISC-04):**
- Text input bound to `q` search param via `useSearchParams`.
- Debounce the value before triggering API fetch (use `useDebouncedValue`).
- Cancel in-flight requests with AbortController when query changes.

**Filter by tag (DISC-05):**
- Render tag filter checkboxes. Tags list can be hardcoded initially or derived from a `GET /api/bundles/facets` endpoint (prefer hardcoded for simplicity in v1).
- Selected tags stored as `tag=X&tag=Y` in URL search params.

**Filter by artifact type (DISC-06):**
- Render artifact type checkboxes: themes, commands, agents, modes, skills, plugins, tools, rules, config.
- Selected types stored as `type=X&type=Y` in URL search params.

**Filter by OpenCode compatibility (DISC-07):**
- Simple text input or dropdown for OpenCode version (e.g., ">=1.0").
- Stored as `opencode=1.0` in URL search params.

**Sort (DISC-08):**
- Sort dropdown: "Newest" (default). Can add "Most Stars" as optional.
- Stored as `sort=newest` in URL search params.

**URL sync behavior:**
- All controls read from and write to `useSearchParams`.
- Back/forward navigation restores filter state correctly.
- Sharing the URL reproduces the same browse view.

**Data fetching:**
- On any query change (debounced for `q`), call `fetchBundles` with current params.
- Show loading state during fetch.
- Show "No bundles found" for empty results.

Style all controls with CSS Modules consistent with the existing Browse page design (dark theme, sharp edges, monospace accents for inputs).
