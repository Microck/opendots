> Personal shell/editor/git defaults for daily development workflows.

I've been refining this setup for years. It's the configuration I install on every new machine - from my laptop to remote servers. Nothing fancy, just solid defaults that work.

## Quick Install

```
Fetch and follow https://opendots.me/INSTALL.md for bundle URL: https://opendots.me/bundle/d0722070-5fc6-4c27-bffa-97bf44c17da9
```

## What you get

**Shell environment** that feels like home:
- Familiar aliases (`ll`, `la`, `gs` for git status)
- Sensible PATH setup
- Prompt that shows git branch

**Git configuration** that stays out of your way:
- Global ignore patterns
- Short aliases for common commands
- Merge tool setup

**Editor settings** for consistency:
- Vim defaults that make sense
- EditorConfig for cross-editor standards

## Why I made this

I'm tired of setting up new machines. This bundle is my "clone and go" solution. Feel free to fork and customize it for your own workflow.
